# Launching a business

Most practices sign up themselves on the website. Use **New business** when we set one up for
them: a pilot, a practice that asked for help, or a demo.

## Set it up

1. **Businesses → New business.** Enter the practice's website. It reads a few pages and drafts
   the details, hours, treatments and answers. Or enter everything by hand.
2. **Review** the draft. Anything it read from the site is marked: check prices and hours with the
   practice before they go live.
3. **Owner**: their e-mail and name. Choose whether to e-mail the invite (the link works for 7 days)
   and whether to mark setup as done. Leave setup open if the owner will run the setup wizard
   themselves.
4. **Number**: none yet, one we already have, or buy one. Australian and UK numbers can take a while:
   see [numbers](numbers.md).
5. **Create.** The last screen has the owner's set-password link to copy, in case the e-mail doesn't
   arrive.

## Then follow the launch checklist

The business page opens with **Launch this business**. Each step ticks itself off as it happens:

| Step | What to do if it's stuck |
|---|---|
| Owner added | Team tab: add them, or resend the link |
| Owner has signed in | Send the set-password link again; check it didn't go to spam |
| Number live | Numbers tab: check the order, or assign one |
| Setup wizard finished | Open as owner and run it with them on a call |
| Test call made | Open as owner, Assistant, Test call |
| First real call answered | Their forwarding isn't on yet: walk them through it |
| DPA accepted | The owner accepts it under Legal & privacy (not you) |
| Pilot or plan set | Controls tab, or Pilots for a free pilot |

When every step is done it shrinks to one line: the practice is live.
